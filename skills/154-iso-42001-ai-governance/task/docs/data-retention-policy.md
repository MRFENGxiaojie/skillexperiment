# Data-retention policy (summary)

- Resume data: kept for 12 months after the recruitment process ends, then auto-deleted
- Training data: roughly 200K historical resumes; must not be used for model training before de-identification
- Access control: only relevant hiring-team members may access resume data
- Logs: system access logs kept for 180 days
