# Karpathy Video: How I Use LLMs (Notes)

Source: https://www.youtube.com/watch?v=EWvNQjAaOHw — Andrej Karpathy, "How I Use LLMs" (talk)

## Key points

- LLMs are best used as a **thinking companion**, not just a chatbot — paste context, ask pointed questions
- **Token budgeting**: keep prompts focused; long context has a cost in focus, not just money
- Karpathy uses a personal "prompt file" with reusable instructions for recurring tasks (writing, coding, reviewing)
- For code, he prefers working in small, verifiable steps and letting the LLM draft + self-critique
- On agents: autonomy is promising but current tools still need supervision and clear verification loops
- Recommended habit: treat the LLM output as a draft that you edit, not as final copy

## Quotes

> "The chat window is not the product — it's the interface to a collaborator."

> "You should be spending more time on the prompt, not the model."

## Takeaways for my workflow

- Set up a prompts file for recurring writing tasks
- Ask for critiques of my drafts instead of one-shot rewrites
- Use step-by-step verification for anything generated that will ship
