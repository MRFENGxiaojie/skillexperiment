# Game Info — "Danzhu Xiaoxiaole"

## Game Type
- Casual puzzle: marble physics + match-3 combination (launch marbles to knock out colored blocks, triggering combo scoring)
- Level-based: 120 levels in total, 5 new levels added every week

## Session Length
- 2-3 minutes per round
- Design goal: fragment time (commuting, waiting in line, lunch break)

## Target Users
- Ages 18-35, casual game players (reference similar titles: Kaixin Xiaoxiaole, Danzhu Chuanqi user profiles)
- Expected female proportion: 55-65%
- Primarily the Chinese market, considering overseas expansion into Southeast Asia

## Current Status
- Developed in Unity; Android has been in internal beta for 3 months
- Test downloads: 20,000+ (channels: TapTap + YingYongBao)
- Retention: 60% of users quit within 5 minutes (below the 20-30 minute session average of similar titles)
- Negative reviews focus on "hard to operate on a phone" and "the phone heats up quickly after a while"
