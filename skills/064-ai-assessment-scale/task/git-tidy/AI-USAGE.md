# AI usage disclosure (draft)

git-tidy is developed by this team with the aid of Cursor + Copilot. AI involvement by area:

- Architecture design: decided by human discussion (CLI tool, single-module layout); AI used for comparing approaches
- Code implementation: about 80% of the backend API (validation logic, CLI) is AI-generated, merged after line-by-line human review
- Testing: all test cases drafted by AI; humans add edge cases (empty commits, overlong lines, invalid scope)
- Docs: README and config docs drafted by AI, rewritten and finalized by humans

> This file is an unpolished draft; official disclosure is in the README badge and notes sections.
