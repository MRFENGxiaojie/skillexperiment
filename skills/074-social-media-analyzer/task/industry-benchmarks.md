# Instagram Industry Engagement Rate Benchmarks (2025-2026 reference values)

Below are the average engagement rates by Instagram content format from third-party statistics
(engagement = likes + comments + shares + saves, using the same definition as this review):

| Content format | Average engagement rate (median) | Excellent line (top 25%) |
|----------|---------------------|------------------|
| Reels    | 1.95%               | 3.20%            |
| Carousel | 1.40%              | 2.40%            |
| Image    | 0.90%              | 1.60%            |
| Stories  | 0.60%              | 1.10%            |

## Click-related Benchmarks (standalone-site traffic-driving scenarios)
- Average click-through rate (CTR) for links attached to Reels captions: 0.5% - 1.0%
- Average click-through rate for links in carousel / image captions: 0.3% - 0.8%
- Cost per link click (CPC, in CNY, when running ads): CNY 2 - 8

## Notes
- Benchmark data source: composite reference values from the public industry reports of RivalIQ and Hootsuite for 2025-2026
- Engagement rate is calculated as "engagement count / reach", consistent with the definition used for organic posts
- The engagement rates of paid posts are generally slightly lower than the organic post average; be mindful of the definition difference when comparing
