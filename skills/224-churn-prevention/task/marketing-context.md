# Marketing Context

## Product
- B2B SaaS project collaboration tool used daily by cross-functional teams.
- Price: $49/month per seat. Current MRR: ~$400K. Payments are processed by Stripe.

## Churn situation
- Monthly churn has risen from 3% to 6% over the last six months.
- Voluntary churn: users who click "cancel subscription" simply disappear - there is no retention flow, no exit survey, no offer, no confirmation screen.
- Involuntary churn: users whose payments fail get one email and are never followed up - no dunning sequence, no card updater, no reactivation, no win-back.
- No win-back / re-engagement program exists today.

## ICP
- Small-to-mid B2B teams (roughly 5-50 seats) using the tool daily for project collaboration.
- Anecdotally observed churn reasons: too expensive for the value perceived, not using enough of the product, missing a feature, switching to a competitor, project ended / seasonal, too complicated, just testing / never really needed.

## Goal
- Systematically reduce voluntary and involuntary churn with a complete cancel flow, a retention offer playbook, and a payment-failure recovery (dunning) sequence; quantify recovered MRR and track metrics continuously.
