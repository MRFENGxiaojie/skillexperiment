# FOUNDER_CONTEXT.md

## Company name
DevAnalytics

## Product positioning
A developer-productivity data analytics tool for engineering teams. It helps engineering leaders answer three questions: where the team's time goes, how fast delivery is, and what's blocking delivery.

## Feature list
- Automatically syncs dev data from GitHub / Jira / Linear (PRs, issues, commits, deployment records)
- Efficiency dashboards at team and individual level (delivery speed, Cycle Time, throughput)
- Automatic blocking-item detection and alerts (stale PRs, changes waiting for review)
- Automated weekly reports, one-click export for management
- Dashboards support custom metrics and filters

## Tech stack
- Frontend: React + TypeScript + Vite
- Backend: Python (FastAPI)
- Data storage: PostgreSQL + Redis
- Deployment: AWS (ECS + RDS)
- Data integration: GitHub App, Jira OAuth, Linear API

## Current beta users
- 12 beta users total (10 are engineer friends of the founding team from previous companies, 2 are from the developer community)
- 5 are active weekly, 3 use it occasionally, 4 signed up but basically never use it
- Beta user feedback: dashboard information density is right, but "I don't know which metric to look at" and "I need someone to tell me what to look at"
- No paid features exist yet, and no fees have been charged

## Team
- 2 founders (both with engineering backgrounds), no dedicated marketing/sales
- Fully committed; monthly cash burn about CNY 25K

## Milestones
- Product is usable and stable (6 months of beta with no major incidents)
- But has never proactively acquired customers; growth relies entirely on word of mouth and personal networks
